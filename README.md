# Coding Contest 2024 25.10.2024 Library

## Description

This is my library for the coding contest 2024.

## Usage

### Setup

If you want you can configure some settings in the [Settings.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/CodingContestHelper/Settings.cs) file.

### Files

- You need to copy the input files into the [input](https://github.com/s-woegerbauer/CodingContest2024_40th/tree/main/CodingContest2024_40th/CodingContest2024_40th/bin/Debug/net8.0/input) folder configured in [Settings.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/CodingContestHelper/Settings.cs).
- The output files will be generated in the [output](https://github.com/s-woegerbauer/CodingContest2024_40th/tree/main/CodingContest2024_40th/CodingContest2024_40th/bin/Debug/net8.0/output) folder configured in [Settings.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/CodingContestHelper/Settings.cs).
- You can write a test input into the [test](https://github.com/s-woegerbauer/CodingContest2024_40th/tree/main/CodingContest2024_40th/CodingContest2024_40th/bin/Debug/net8.0/test) folder configured in [Settings.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/CodingContestHelper/Settings.cs).
- The test output will be generated in the [test](https://github.com/s-woegerbauer/CodingContest2024_40th/tree/main/CodingContest2024_40th/CodingContest2024_40th/bin/Debug/net8.0/test) folder configured in [Settings.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/CodingContestHelper/Settings.cs).

### Coding

- You can start coding in the [Program.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/Program.cs) file.
- Write your code in the Solution method.
- You will get a List<string> as input and you need to return a List<string> as output.
- The input and output files will be read and written automatically.

### Testing
- You can uncomment the test method in the [Program.cs](https://github.com/s-woegerbauer/CodingContest2024_40th/blob/main/CodingContest2024_40th/CodingContest2024_40th/Program.cs) file.
```csharp
Master.Test();
```
- This will read the test input files and see if the output is equivalent to the one given in the test output file => that is the expected output.
